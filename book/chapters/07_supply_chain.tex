\section{Supply Chain Structure / Lieferketten-Struktur / 供应链结构}

\begin{otherlanguage}{ngerman}
Edekas Lieferkette umfasst:
\begin{itemize}
    \item \textbf{Beschaffung}: Globale und regionale Lieferanten
    \item \textbf{Produktion}: Eigene Produktionsstätten
    \item \textbf{Logistik}: Zentrale und regionale Distributionszentren
    \item \textbf{Vertrieb}: Multi-Channel-Vertrieb (Filialen, Online)
\end{itemize}
\end{otherlanguage}

Edeka's supply chain includes:
\begin{itemize}
    \item \textbf{Sourcing}: Global and regional suppliers
    \item \textbf{Production}: Own production facilities
    \item \textbf{Logistics}: Central and regional distribution centers
    \item \textbf{Distribution}: Multi-channel distribution (stores, online)
\end{itemize}

艾德卡的供应链包括：
\begin{itemize}
    \item \textbf{采购}：全球和区域供应商
    \item \textbf{生产}：自有生产设施
    \item \textbf{物流}：中央和区域配送中心
    \item \textbf{分销}：多渠道分销（门店、在线）
\end{itemize}
